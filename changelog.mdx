## August 20, 2026

### New features

- **Confetti, on demand.** A 🎉 button now lives in the top nav. Tap it whenever the mood strikes and the page throws a proper celebration. Auto-confetti on page load is gone, so the site loads quietly until you ask for a party.
- **Secret burst.** Type three up-arrows anywhere on the site for a hidden confetti moment. Old secret handshake retired.

### Updates

- **New banner.** The top-of-page banner now reads *"The New York Knicks are NBA champions!"* — because they are, and it still feels good to say.
- **Cleaner navbar.** Removed the "Banner No. 3" primary button from the top nav to keep the header focused on content. The [Go Knicks](https://www.nba.com/knicks) link stays.

### Bug fixes

- **Stat tiles now render reliably.** The animated count-up on the numeric tiles (see [53 Years](/index) and [The Numbers](/numbers)) was occasionally getting stuck partway. Tiles now render their final values immediately, every time.
