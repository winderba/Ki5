## August 20, 2026

### New features

- **Español is here.** The full site is now available in Spanish. Use the EN/ES language switcher in the top nav to toggle between the two, or jump straight to the Spanish [53 Años](/es/index), [La Serie](/es/series), [Juego 4](/es/game4), [Los Números](/es/numbers), [El Desfile](/es/parade), [La Afición](/es/fans), [El Roster](/es/roster), and [Colofón](/es/colophon).

## Earlier this week

### New features

- **Confetti, on demand.** A 🎉 button now lives in the top nav. Tap it whenever the mood strikes and the page throws a proper celebration. Auto-confetti on page load is gone, so the site loads quietly until you ask for a party.
- **Secret burst.** Type three up-arrows anywhere on the site for a hidden confetti moment. The old secret handshake is retired.

### Updates

- **New banner.** The top-of-page banner now reads _"The New York Knicks are NBA champions!"_. Because they are, and it still feels good to say.
- **Cleaner navbar.** We removed the "Banner No. 3" primary button from the top nav to keep the header focused on content. The [Go Knicks](https://www.nba.com/knicks) link stays.

### Bug fixes

- **Stat tiles now render reliably.** The animated count-up on the numeric tiles (see [53 Years](/index) and [The Numbers](/numbers)) sometimes got stuck partway. Tiles now render their final values immediately, every time.
