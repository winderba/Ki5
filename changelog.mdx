## October 1, 2026

### Updates

- **Clearer page titles.** [The Legends](/roster) now opens with "2026 Knicks championship roster," and [Behind the Banner](/colophon) with "How this Knicks tribute site was built." The sidebar keeps the short names you know.
- **Better search previews.** The [Changelog](/changelog) now has a summary, so links to it show a helpful preview in search results and when shared.

## September 30, 2026

### Updates

- **New look.** The whole site now wears a green brand palette, from deep forest backgrounds to bright lime accents. Heroes, trading cards, stat tiles, scoreboards, and the Dolan Watch box all got the update.
- **New type.** Big titles now use an elegant serif, body copy stays in Inter, and tags and captions use a clean monospace.
- **Section labels on every page.** Each page now shows its section name above the title, so you always know where you are.
- **Matching charts and confetti.** The [series](/series) and [Game 4](/game4) comeback charts, plus the 🎉 confetti, now use the new colors.
- **Colophon refreshed.** [Colophon](/colophon) now describes the new palette and fonts.

## August 20, 2026

### New features

- **Español is here.** The full site is now available in Spanish. Use the EN/ES language switcher in the top nav to toggle between the two. You can also jump straight to the Spanish pages: [53 Años](/es/index), [La Serie](/es/series), [Juego 4](/es/game4), [Los Números](/es/numbers), [El Desfile](/es/parade), [La Afición](/es/fans), [El Roster](/es/roster), and [Colofón](/es/colophon).

## Earlier this week

### New features

- **Confetti, on demand.** A 🎉 button now lives in the top nav. Tap it whenever the mood strikes and the page throws a proper celebration. Auto-confetti on page load is gone, so the site loads quietly until you ask for a party.
- **Secret burst.** Press the up arrow three times anywhere on the site for a hidden confetti moment. The old secret handshake is retired.

### Updates

- **New banner.** The top-of-page banner now reads _"The New York Knicks are NBA champions!"_. Because they are, and it still feels good to say.
- **Cleaner navbar.** We removed the "Banner No. 3" primary button from the top nav to keep the header focused on content. The [Go Knicks](https://www.nba.com/knicks) link stays.

### Bug fixes

- **Stat tiles now render reliably.** The animated count-up on the numeric tiles (see [53 Years](/index) and [By the Numbers](/numbers)) sometimes got stuck partway. Tiles now render their final values immediately, every time.
